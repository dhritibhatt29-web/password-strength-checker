
# Password Strength Checker

## About the Project
This is my first beginner-level cybersecurity project,
developed using Python.

It checks password strength based on five conditions.

## Features
- Checks password length.
- Checks uppercase letters.
- Checks lowercase letters.
- Checks numbers.
- Checks special characters.
- Calculates a password strength score.
- Classifies passwords as Weak, Moderate, or Strong.

## Technologies Used
- Python
- Regular Expressions (re module)
- Visual Studio Code

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python password_checker.py

## Learning Outcome
Through this project, I learned basic Python programming,
conditional statements, regular expressions, and password
security concepts.
